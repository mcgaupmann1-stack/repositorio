**Pre‑entrega evaluable: Brief analítico del proyecto RetailPro**
Este módulo contiene la primera pre‑entrega evaluable del proyecto integrador RetailPro.
El objetivo es definir la base estratégica del análisis antes de construir la base de datos y el dashboard en módulos posteriores.

La entrega incluye las 5 secciones obligatorias:

Problema de negocio
Fuentes de datos
Preguntas de análisis
KPIs
Boceto del dashboard


**1. Problema de negocio**
La pregunta estratégica definida para RetailPro es diagnóstica y accionable:

“¿Por qué las ventas de la categoría Notebooks cayeron un 15% en la región Norte durante el último trimestre, y qué factor —precio, quiebre de stock o mix de canal de venta— lo explica principalmente?”

Esta pregunta guía todo el proyecto y determina qué datos se necesitan y qué análisis se realizarán en los módulos siguientes.

**2. Fuentes de datos identificadas**
El sistema de análisis se construirá sobre cuatro tablas principales:

Clientes — quiénes compran
Incluye identificación, segmento, región y fecha de alta.

Productos — qué se vende
Incluye categoría, precio de lista y stock disponible.

Ventas — las transacciones
Registra fecha, cliente, producto, territorio, cantidad, monto total y canal de venta.

Territorios — dónde ocurren las ventas
Define región, provincia/estado y responsable comercial.

**3. Preguntas de análisis**
El brief incluye 6 preguntas clave que el dashboard final debe responder, entre ellas:

Evolución mensual de ventas y detección de caídas
Categorías que explican la caída en la región Norte
Relación entre stock y caída de ventas
Comparación de desempeño entre regiones
Análisis por canal de venta
Productos con mayor caída porcentual trimestre a trimestre
Estas preguntas guían el diseño del modelo de datos y los KPIs.

**4. KPIs propuestos**
El documento incluye los indicadores clave que se visualizarán en el dashboard:

Total Ventas
Ticket Promedio
Variación % de Ventas (MoM)
Participación por Categoría
Rotación de Stock

Cada KPI está acompañado de su descripción y fórmula conceptual.

**5. Boceto del dashboard**
El módulo incluye un boceto conceptual del dashboard ejecutivo, con:

KPIs en la parte superior
Comparación regional y temporal
Participación por categoría
Tabla de productos con mayor caída

Este boceto define la estructura visual que se implementará en Power BI en módulos posteriores.
